# Описание проекта: Исследование факторов неравенства на основе API WID World

## Файлы проекта

**Документация (docs/)** — единственный источник правды по методологии GRACE:
- `requirements.xml` — цели, 6 use case (UC-1..UC-6), критерии приёмки
- `technology.xml` — стек (Python 3.10, pandas, matplotlib, pytest, ruff) + инструменты PDF-экспорта
- `development-plan.xml` — фазы P-0..P-6, задачи T-1..T-7 со статусами
- `verification-plan.xml` — тестовые наборы TS-1..TS-7 (каждый модуль → свой UC)
- `knowledge-graph.xml` — граф модулей M-1..M-8, зависимости, статусы
- `session-log.md` — журнал сессий
- `glossary.md` — термины + выбранные показатели неравенства с источниками
- `report.md` — итоговый отчёт (PDF-версия генерируется, gitignored)

**Код (src/)** — каждый модуль с XML-контрактом MODULE_CONTRACT в докстринге:
- `config.py` (M-8) — 28 стран, 12 переменных, период, порог корреляции
- `wid_client.py` (M-2) — клиент API WID с кэшированием (UC-1)
- `time_series_analysis.py` (M-3) — временные ряды, корреляции, тепловые карты (UC-2)
- `cross_section_analysis.py` (M-4) — кросс-страновый анализ, scatter plots (UC-3)
- `analysis_comparison.py` (M-5) — сопоставление подходов, проверка устойчивости (UC-4)
- `indicator_selection.py` (M-6) — выбор показателя по литературе (UC-5)
- `report.py` (M-7) — генерация отчёта MD + PDF (UC-6)
- `main.py` (M-1) — файл-пример паттерна

**Скрипты запуска (run_*.py)** — воспроизводимые шаги: `run_uc2.py`..`run_uc6.py`, плюс `uc5_research.py` (Perplexity-ресерч).

**Тесты (tests/)** — по одному файлу на модуль (`test_wid_client.py` и т.д.), `conftest.py` — загрузка `.env`.

**Артефакты (gitignored):** `data_wid.csv` (11035 строк), `output/` (CSV, графики), `.cache/wid/` (кэш API).

## Ключевые выводы исследования

1. **Концентрация богатства (доля топ-1%)** — единственный устойчивый коррелят неравенства доходов и во времени, и между странами (r≈0.7–0.8).
2. **ВВП/доход на взрослого не робастен** как фактор неравенства (исторически нестабилен, кросс-секционно слаб).
3. **Выбранные показатели неравенства** — доля топ-1% и индекс Джини (pre-tax), согласно DINA Guidelines 2025.
