# Глоссарий проекта

| Термин | Определение | Имя в коде |
|---|---|---|
| WID World | World Inequality Database — база данных о распределении доходов и богатства | `wid` |
| Доля доходов топ-1% | Доля национального дохода, получаемая верхним 1% населения | `top1_share` |
| Доля доходов топ-10% | Доля национального дохода, получаемая верхними 10% населения | `top10_share` |
| Индекс Джини | Мера неравенства распределения доходов, от 0 (равенство) до 1 (полное неравенство) | `gini` |
| Коэффициент Тейла | Мера неравенства на основе энтропии, чувствительна к изменениям наверху распределения | `theil` |
| P90/P10 | Отношение доходов 90-го перцентиля к 10-му | `p90_p10_ratio` |
| Индекс Аткинсона | Мера неравенства с параметром неприятия неравенства (epsilon) | `atkinson` |
| Pre-tax national income | Доналоговый национальный доход (до налогов и трансфертов) | `sptinc` |
| Post-tax disposable income | Посленалоговый располагаемый доход | `sptinc_disposable` |
| Доля труда в ВВП | Доля национального дохода, идущая на оплату труда | `labshare` |
| ВВП на душу населения | Валовой внутренний продукт на человека | `gdppc` |
| Неравенство доходов vs богатства | Различие между неравенством потоков дохода и неравенством запасов активов | — |
