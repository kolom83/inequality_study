# ADR-000: Инициализация проекта по методологии GRACE

- **Статус:** принято
- **Дата:** 2026-08-02

## Контекст
Проект разрабатывается совместно с LLM в многосессионном режиме. Требования к исследованию факторов неравенства зафиксированы в `docs/requirements.xml` (UC-1..UC-6). Данные загружаются только через официальный API WID World.

## Решение
1. Используется методология GRACE: контракты → код.
2. Формат документации — XML: строгая структура, однозначный парсинг для LLM, возможность валидации.
3. `knowledge-graph.xml` — единственное место описания структуры проекта.
4. Секреты (ключи API Perplexity и WID) хранятся в `.env`, исключённом из git; для новых сессий — `.env.example`.
5. Тестовый фреймворк — pytest, линтер — ruff (установлены в окружение Python 3.10).

## Последствия
- Больше токенов на документацию, но меньше расхождений между сессиями.
- Любое изменение архитектуры требует нового ADR.
- Загрузка данных из WID выполняется напрямую по API с кэшированием ответов (требование requirements.xml).
