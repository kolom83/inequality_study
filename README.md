# Исследование факторов неравенства на основе API WID World

Исследование взаимосвязей между показателями неравенства и социально-экономическими индикаторами с использованием данных WID World. Выделить показатели, наиболее сильно коррелирующие с неравенством как в исторической динамике отдельных стран, так и в кросс-секционном разрезе между странами, и обосновать выбор наиболее релевантного показателя неравенства.
